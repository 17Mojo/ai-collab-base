# 第一次试用指南（Prompt Pack 扩展）

> 给**没用过这个扩展**的人看的。全程 5 步，大约 10 分钟。
> 你不需要会写代码，也不需要改任何配置文件——只要能装一个 Chrome 扩展。
>
> 这是一次**试用**，不是正式发布版。麻烦你把卡住的地方记下来（最后有 3 个问题），
> 我们要靠你的反馈把这条路修通。

---

## 0. 这是个什么东西

一个 Chrome 扩展，装上之后它能替你把一段固定的话发给 AI 聊天网站，
并把 AI 的回复取回来——相当于「把一段话存成按钮，点一下就发出去」。

**我们目前只做到「冒烟自检」这一步**：整个链路能跑通一次就算成功。

---

| 一台能跑代码的电脑 | **只有**在「扩展还得自己编译」时才需要（见步骤 1）。如果有人直接给了你一个装好的扩展文件夹，就不用 |

## 2. 五步走

### 步骤 1 · 把扩展编译出来

> **如果有人直接给了你一个装好的扩展文件夹**（里面能看到 `manifest.json`），
> **这一步跳过**，直接看步骤 2。

在项目根目录下执行：

```bash
cd chrome-extension
npm install
npm run build
```

**成功标志**：屏幕上出现 `=== Build Complete ===`，并且 `chrome-extension/dist/` 目录出现了。

### 步骤 2 · 装进 Chrome

1. 打开 `chrome://extensions`（在地址栏直接输入这串字就行）
2. 右上角打开**开发者模式**
3. 点**加载已解压的扩展程序**
4. 选 `chrome-extension/dist` 这个**文件夹**（不是里面的文件）。
   如果你拿到的是别人给的一个装好的文件夹，就选那个文件夹。

**成功标志**：扩展列表里出现「AI Collab System - Prompt Pack」。

### 步骤 3 · 打开 AI 网站（**装好之后再打开**）

打开千问（`https://www.qianwen.com/`），登录，随便问一句话。

> **顺序很重要**：扩展的内容脚本是在页面打开的那一刻注入的。
> 如果你**先**打开了网站、**后**才装扩展，那个页面里是没有扩展的——
> 装好之后把已经打开的 AI 页面**刷新一下**（F5）就行。

**成功标志**：页面正常显示，能对话。

### 步骤 4 · 导入那个「冒烟自检」Pack

1. 点浏览器右上角的扩展图标（一个拼图形状，可能藏在那个小箭头里）
2. 在弹出的窗口里点 **「📥 导入 / 管理 Pack」**
3. 会打开一个「Pack 编辑器」页面，在页面下方找到 **「📥 导入 Pack」**，点它
4. 选这个文件：`packs/examples/external-user-smoke.json`
   （在项目根目录下面；文件选择窗口里可以直接输入路径。
   如果你拿到的是别人打包好的一堆文件，那这个 `.json` 就在那一堆里面）
5. 选好后会出现「合并 / 覆盖」两个选项，**保持默认的「合并」**，点 **「确认导入」**

**成功标志**：页面底部的状态栏显示 `导入成功: 1 个 Pack`。

### 步骤 5 · 跑一次

1. 切回那个 AI 网站的标签页
2. 点扩展图标 → 点列表里的 **「冒烟自检」**
3. 等待大约 10～30 秒

> 提示词只会发到**你当前所在的这个标签页**——扩展会精确定位到它，
> 不会发到你别的标签页里去。

**成功标志**：AI 聊天框里出现并自动发出这句话

> 请只回复这一句话，不要添加任何其他内容：你好，Prompt Pack 冒烟自检通过。

然后 AI 回复里**包含**「你好，Prompt Pack 冒烟自检通过。」就算成功
（AI 多说几个字没关系）。

## 3. 卡住了怎么办

| 你看到的 | 多半是 | 你可以做的 |
|---|---|---|
| 扩展图标点了没反应 | 装的时候选错目录了（选了 `dist` 里的某个文件而不是 `dist` 文件夹） | 回到步骤 2 卸掉重装 |
| 导入 Pack 时提示「文件格式错误」 | 选的文件**不是 JSON 文件**（比如选成了目录里的别的文件） | 确认选的是 `packs/examples/external-user-smoke.json` 这个 **.json 文件** |
| 导入 Pack 时提示「没有找到任何 Pack」 | 文件是 JSON，但里面没有 Pack（选错文件了） | 确认选的是 `packs/examples/external-user-smoke.json` 这个 **.json 文件** |
| 点了「冒烟自检」，输入框里**什么都没出现** | 我们没能在这个网站的输入框里正确写入文字 | **这就是我们要你告诉我们的**——把这一步记下来，问卷第 1 题选「提示词没进输入框」 |
| 输入框里**有字**，但旁边的发送按钮是**灰的**、点不动 | 这个网站的输入框是「富文本编辑器」，文字看着进去了但**网站自己没收到** | 同上（问卷第 1 题选「提示词没进输入框」）——**这是我们的 bug，不是你操作错了** |
| 提示词发出去了，但 AI 一直没回 / 一直转圈 | 我们在等回复的判断条件可能不对 | 记下来，问卷第 1 题选「发出去了但等不到回复」 |
| AI 回话了，但扩展说「执行失败」 | 同上 | 把扩展弹窗里那行红字**原样抄下来**，问卷第 2 题要它 |
| 页面上多了好几次同样的提问 | **这不该发生**——扩展只发给你当前所在的那个标签页 | 记下来告诉我们（第 2 题附截图） |

## 4. 已知限制（**试用前请看一眼**）

这些不是你的操作问题，是我们这边确实还没做完的：

1. **真实发送这条路我们自己也还没在真机上跑过一次。**
   我们验证过的是「扩展能装上、能找到输入框」这类环节；
   「点一下 → 真的发出去 → 把回复取回来」这一整条，
   **至今没有任何一次真机验证记录**。所以你这次很可能是在帮我们抓 bug。
2. **「有适配器」不等于「验证过」。** 上面列的 10 个网站是扩展里**写了适配器**的：
   - 千问、文心一言、元宝、Kimi、智谱清言、LongCat、Gemini——
     我们采到过这些站点的**真实页面结构**，但没跑过真实发送；
   - ChatGPT、Claude、DeepSeek——**连页面都没进去过**
     （撞人机校验或登录墙），这三个基本等于没测；
   - 豆包之类**没有适配器**的网站：完全不行。
3. **扩展弹窗里没有输入框。** 现在只能跑「提示词写死在 Pack 里」的自检；
   想要自己传内容，暂时只能在 Pack 编辑器里改。
4. **界面语言可能有影响。** 我们的按钮定位有些依赖页面上的固定属性，
   英文界面和中文界面的表现不一定一样，而且**我们没验证过「同一个网站换一种语言」**
   ——这次先试你平时用的语言。
5. **有些网站的输入框是「富文本编辑器」**（文字看着进了框，但网站自己其实没收到）。
   我们在**千问**上验过这一层，在别的网站上**没验过**。
   如果你看到「文字进去了但发送按钮是灰的」，那就是这个问题——
   请记下来告诉我们（第 3 节有对应的说明）。
6. 请**不要**用它处理任何隐私内容、公司机密、账号密码之类的东西。
   它的作用就是把文字发给 AI 网站而已，发出去的内容你自己看着办。

## 5. 三个问题（麻烦你了）

用你自己的话回答就行，不用写技术细节。

**问题 1：你在哪一步卡住了？**
（选一个，或者自己写）
- A. 装扩展那一步就不顺
- B. 导入 Pack 那一步不顺
- C. 点了 Pack，但**提示词没进输入框**
- D. 提示词发出去了，但**等不到回复**
- E. AI 回话了，但**内容不对**
- F. 一次就成功了（那太罕见了，请务必确认一下）

**问题 2：现场信息**
- 用的哪个网站？
- Chrome 是什么版本？
- 界面是中文还是英文？
- 有报错的话，把**原样文字**抄过来（或者截图发给我们）

**问题 3：这个东西对你有用吗？**
- 你会再用一次吗？会用在什么场景？
- 哪里让你觉得别扭、或者不放心？
