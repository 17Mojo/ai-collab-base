# 用户验收测试 (UAT) 场景

**版本**: v1.0.0
**日期**: 2026-04-29

---

## 一、UAT 目标

验证 AI Collab System 核心功能满足用户需求：
1. Pack 创建与管理
2. 知识增强功能
3. Studio 生成功能
4. Extension 安装与使用

---

## 二、测试场景

### 场景 1: Pack 创建流程测试

**用户故事**: 用户上传 Pack JSON，验证结构并执行 Pack。

**前置条件**:
- 后端服务运行 (`http://localhost:8000`)
- 用户有管理员权限

**测试步骤**:

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 打开 Extension Popup | 显示平台选择界面 |
| 2 | 选择 "Pack 管理" 标签 | 显示 Pack 列表 |
| 3 | 点击 "上传 Pack" 按钮 | 打开文件选择对话框 |
| 4 | 选择 `packs/examples/ai_collab_intro.json` | 显示上传进度 |
| 5 | 点击 "验证" 按钮 | 显示验证结果 ✅ |
| 6 | 点击 "执行 Pack" 按钮 | 开始执行，显示进度 |
| 7 | 观察执行结果 | 显示步骤执行状态 |
| 8 | 查看执行日志 | 显示详细执行记录 |

**验收标准**:
- ✅ Pack 上传成功
- ✅ 验证通过（无错误）
- ✅ 执行完成，显示结果
- ✅ 日志记录完整

### 场景 2: 知识增强功能测试

**用户故事**: 用户输入问题，NotebookLM 查询相关知识并注入 AI 响应。

**前置条件**:
- NotebookLM 已认证
- 知识源已配置（21+ 文档）

**测试步骤**:

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 打开 Extension Popup | 显示主界面 |
| 2 | 选择目标平台（如 ChatGPT） | 显示平台适配器状态 ✅ |
| 3 | 在输入框输入问题 "什么是 Prompt Pack?" | 文字输入成功 |
| 4 | 点击 "知识增强" 按钮 | 显示 NotebookLM 查询状态 |
| 5 | 观察 NotebookLM 响应 | 显示查询结果（来源标注） |
| 6 | 点击 "注入知识" 按钮 | 知识内容插入输入框 |
| 7 | 点击 "发送到 AI" 按钮 | AI 响应包含来源引用 |
| 8 | 检查缓存命中状态 | 显示缓存命中提示（第二次查询） |

**验收标准**:
- ✅ NotebookLM 查询返回内容
- ✅ 知识准确注入到输入
- ✅ AI 响应包含来源标注
- ✅ 缓存命中显示节省时间

### 场景 4: Extension 安装测试

**用户故事**: 用户加载 Extension 到 Chrome，配置并使用功能。

**前置条件**:
- Chrome 浏览器已安装
- Extension 包已准备 (`dist/ai-collab-extension-v0.1.0.zip`)

**测试步骤**:

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 解压 Extension ZIP 包 | 得到 `chrome-extension/` 目录 |
| 2 | 打开 Chrome 浏览器 | Chrome 正常运行 |
| 3 | 访问 `chrome://extensions/` | 显示扩展管理页面 |
| 4 | 开启 "开发者模式" | 显示开发者选项 |
| 5 | 点击 "加载已解压的扩展程序" | 打开目录选择对话框 |
| 6 | 选择 `chrome-extension/` 目录 | Extension 加载成功 |
| 7 | 观察 Extension 图标 | 工具栏显示 Extension 图标 |
| 8 | 点击 Extension 图标 | 显示 Popup 界面 |
| 9 | 点击 "设置" 标签 | 显示配置选项 |
| 10 | 配置后端 URL `http://localhost:8000` | 配置保存成功 |
| 11 | 测试连接按钮 | 显示连接成功 ✅ |

**验收标准**:
- ✅ Extension 加载成功
- ✅ Popup 界面正常显示
- ✅ 设置可配置并保存
- ✅ 功能可用（Pack 选择、执行）

## 六、已知问题与限制

1. **NotebookLM 查询**: 需要手动认证，首次使用需浏览器登录
2. **平台适配**: Gemini 和 ChatGPT 页面可能受 CORS 限制
3. **Extension 更新**: 开发者模式每次启动 Chrome 提示禁用
4. **缓存容量**: NotebookLM 缓存上限 100 条目
