## 4. 根因与修复对照（三轮各钉死一个）

1. **首跑 →「太早成功」**：`isTyping()` 未命中千问「努力工作中 用时N秒」+ 空/碎片不判失败 ⇒ 消息气泡一出现就返回。
   → PR #21：内容稳定性等待 ① + 碎片阈值（20 字）③。
2. **复跑一 → 17 字过 20 字闸悖论**：**N15 SW ScriptCache 粘连**——`dist/` 重建后持久 profile 的
   `Default/Service Worker/ScriptCache/<hash>_0` 仍按 URL 粘住旧 SW（内容脚本每次注入读盘是新的，
   SW 是旧的 ⇒ 闸门静默失效）。判无效 run，回执留档为 `.stale-sw-contaminated.*`。
   协议：跑前清 `Default/Service Worker|Code Cache|Extension Scripts` + SW 自检探针
   （`hasGate/hasStatusSelector/hasMin50`，任一 false 即中止）。
3. **复跑二 → 三路绕闸**（干净 SW 下 20–41 字污染 ack 仍 `success=True`）：
   - ① pause-leak：「✨ 努力工作中 用时N秒」状态行没被 `isTyping()` 认出，思考停顿骗过 4s 稳定窗；
   - ② 抽取污染：`extractMessageContent` 全卡 `textContent` 回退，把「正在思考中/阅读技能并构思」状态条拼进正文（25–41 字）；
   - ③ 阈值压线：带主题 ack 20–26 字恰好 `>= 20` 过闸。
   → PR #22：typingIndicator 补 census 选择器（`button[data-status="working"]`、`[class*="generatingThinking"]`）+ 抽取契约收紧（自身→后代→无命中返回空串）+ 阈值 20→50（step 级 `min_output_length` 可覆写）+ 稳定窗 4s→8s。
4. **复跑三 → 全过**。166/166 测试绿，CI 41 条变异全杀（每条新锚由对应命名测试杀死）。
