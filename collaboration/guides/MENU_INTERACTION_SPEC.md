# /menu 交互设计规范

**版本**: 1.0.0  
**状态**: 设计草案  
**目的**: 定义常态化配置服务的交互流程与界面规范

---

## 一、设计理念

`/menu` 是 AI Collab Base 的**运行时控制台**，而非一次性配置向导。

核心原则：
- **随时可调用**: 不依赖特定时机，用户可随时输入 `/menu` 调整配置
- **即时生效**: 配置变更立即生效，无需重启项目或会话
- **历史兼容**: 保持历史任务格式兼容，平滑过渡
- **可审计**: 所有变更记录到 history，支持快照回滚

## 二、入口设计

### 2.1 触发方式

```
用户输入: /menu

系统响应:
┌─────────────────────────────────────────────────────┐
│  ⚙️  AI Collab Base - 控制面板                       │
│                                                     │
│  当前状态: 单 Agent 模式 (Claude Code)              │
│  角色数: 3 (1 活跃, 2 休眠)                          │
│  命令映射: A.RUN, X.RUN, C.RUN                      │
│                                                     │
│  ────────────────────────────────────────────────  │
│  [1] 角色管理 (Role Registry)                       │
│  [2] Agent 绑定 (Binding Map)                       │
│  [3] 命令配置 (Command Prefixes)                    │
│  [4] 工作模式切换 (Startup Mode)                     │
│  [5] 快照与回滚 (Snapshots)                         │
│  [6] 导出/导入 (Export/Import)                      │
│  [7] 检测 Agent 服务商 (Detect Providers)           │
│  [8] 查看历史 (Change History)                      │
│  [0] 退出                                          │
│                                                     │
│  输入数字选择功能，或按 Esc 退出                    │
└─────────────────────────────────────────────────────┘
```

### 2.2 快捷参数

支持命令行风格快捷参数：

```bash
/menu roles              # 直接进入角色管理
/menu bind               # 直接进入绑定管理
/menu detect             # 直接检测服务商
/menu export --output config_backup.json
/menu rollback --id snap_001
/menu help               # 显示帮助文档
```

## 四、运行时行为规范

### 4.1 配置变更即时生效

所有 `/menu` 中的配置变更立即生效：

```python
# 示例: 角色激活后立即可用
用户激活 AGENT_ARCH → Codex CLI
→ binding.status = active
→ binding.provider = "codex_cli"
→ 立即可使用 X.RUN 命令 (映射到 AGENT_ARCH)
→ 无需重启会话或项目
```

### 4.2 变更前自动快照

重大变更前自动创建快照（`runtime_policy.snapshot_before_change = true`）：

```json
{
  "snapshots": [
    {
      "snapshot_id": "snap_015",
      "timestamp": "2026-05-14T11:30:00Z",
      "trigger": "auto_before_change",
      "config_copy": {...}
    }
  ]
}
```

### 4.3 确认门禁

重大变更需要用户确认（`runtime_policy.require_confirmation = true`）：

- 角色删除
- 命令重定义
- 模式切换
- 回滚操作
- 导入替换配置

### 4.4 历史兼容保证

`command_prefixes.history_compatible = true` 时：

```python
# 历史任务格式自动转换
旧格式: C.ACK|task=TASK-001
→ 自动解析为: AGENT_TEST.ACK|task=TASK-001
→ 即使 C.RUN 已重定义为 AGENT_PERF
→ 历史格式仍正确解析

新格式: PERF.RUN
→ 映射到 AGENT_PERF
→ 即时生效
```
