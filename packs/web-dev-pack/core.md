# Web 开发核心规则

## 通用原则

1. **代码可读性优先**
   - 函数长度不超过 50 行
   - 一行代码不超过 100 字符
   - 使用有意义的变量名和函数名
   - 复杂逻辑必须添加注释

2. **安全性优先**
   - 所有用户输入必须验证和转义
   - 使用参数化查询防止 SQL 注入
   - 避免在前端暴露敏感信息
   - 使用 HTTPS 通信

3. **性能优化**
   - 资源文件使用 CDN
   - 图片使用 WebP 格式并设置尺寸
   - 使用懒加载技术
   - 实现代码分割

## 前端规范

- 使用语义化的 HTML 标签
- CSS 遵循 BEM 命名规范
- JavaScript 使用 ES6+ 语法
- 使用 TypeScript 添加类型安全
- 组件化设计，单一职责原则

## 后端规范

- RESTful API 设计
- 使用 JWT 进行身份认证
- 实现日志记录和错误处理
- 数据库操作使用事务
- 缓存常见查询结果

## 测试要求

- 单元测试覆盖率 ≥ 80%
- 集成测试覆盖关键流程
- 端到端测试模拟用户场景
- 性能测试监控响应时间
