并行 bash 调用中，若其中一条命令对不存在的目录/路径报错（如 `ls src/ai_collab/` 目录不存在），可能导致整批并行调用被 abort（`Tool execution aborted`），即使其他命令本可成功。**校验多个路径或执行可能失败的命令时，改用单条命令逐个执行，而非并行混合**。

**Why:** 2026-09-19 两次复现：
1. 并行发出 3 条命令（2 条 bash + 1 条 grep），其中 `ls src/ai_collab/` 因目录不存在报错，导致前两条 bash 调用被中断，仅第三条 grep 成功。
2. gap analysis 时并行批次中 `ls config/*.schema.json` glob 不匹配 → ls 退出码 2 → 整批 abort，连本可成功的 bash 1 也被中断。用户追问"为什么总是卡住"后定位到同一根因。

**How to apply:**
- 当并行调用中包含可能失败的命令（ls 不确定路径、glob 可能无匹配、grep 可能无匹配等）时，拆分为单条逐个执行
- 确定路径存在性的校验命令，不要与正常工作命令混在同一并行批次中
- 若必须并行，先用一条安全命令确认路径存在，再并行执行后续操作
- 注意 glob 不匹配与目录不存在都会让 ls 退出码 2，二者均会触发整批 abort
- 适用于：路径校验、目录探测、glob 探测、不确定是否存在的文件读取等场景
