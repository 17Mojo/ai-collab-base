用户在本项目中通过本地服务 `http://127.0.0.1:1234`（疑似 LM Studio 本地 LLM 默认端口）请求对"需确认的决策点"给出决策建议。2026-09-26 曾以 `http://127.0.0.1:1234` 加上一串 hash（形如 `ba40603e7f8c3ddb5be3cb9eb5ef83ed0f6e5fc1`，疑似会话/请求 ID）要求对 3 个决策点给出决策建议。

**How to apply:** 当用户给出 `http://127.0.0.1:1234` 或要求"对决策点给出建议"时，视为调用该本地 LLM 服务作为第二意见来源；先探测服务类型/可用模型再按其 API 调用。该端点用于辅助决策确认，而非替代用户最终拍板。
