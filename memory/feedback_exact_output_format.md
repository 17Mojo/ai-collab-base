---
name: 严格输出格式约束须逐字照办
description: 用户给出字数/格式/字符集约束（如只回一个词）时，输出必须仅含被要求内容，不加解释、前后缀或 Markdown 包裹
type: feedback
from: Agent
---

当用户下达带**显式输出约束**的指令（固定字数、单词数、字符集、格式，如 "Reply with exactly one word: OK"）时，回复必须逐字照办：只输出被要求的内容本身，不加解释、不加前后缀、不加引号或 Markdown 包裹、不附加"已完成"之类的提示。

**Why:** 2026-10-23 出现过一条仅含格式约束的指令（要求恰好回一个词），正确行为是输出 `OK` 一个词。这类约束常用于校验 Agent 是否严格遵守指令、或作为真实任务前的连通性/格式自检；若擅自"helpful 地"补充说明，约束即失效。

**How to apply:**
- 遇到明确格式/长度/字符约束时，约束优先于"解释原理""结构化输出"等默认习惯
- 只做一次输出，不复述约束本身
- 同源要求：命令式短指令（"重试""继续未完成任务"）也只推进不解释，closeout/RESULT 同样不写流程仪式
